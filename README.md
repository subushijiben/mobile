# Mobile-Island · 屏幕顶边的灵动岛提醒

**Mobile-Island** 是一个常驻 Windows 屏幕顶边的「灵动岛」式小工具：到点弹出一块会变形的岛、响一声、显示倒计时；没事的时候它就是顶边上的一枚小时钟。

单文件、免安装，双击自动部署到用户目录并常驻托盘，不写系统目录、不需要管理员权限。

界面全部用 Win32 API + 分层窗口（Layered Window）逐像素自绘，没有 Electron、没有运行时依赖，一个 exe 就是全部。

> 名字里的 **Island** 就是这块岛。搜 `Mobile-Island`、`灵动岛提醒`、`桌面倒计时` 都能找到它。

## 它是干什么的

最初是给教室做的上下课提醒 —— 上课铃、下课铃、课间倒计时。但闹钟就是闹钟，现在它面向的是**任何「到点提醒我一下」的场景**：

| 场景 | 怎么用 |
| --- | --- |
| 上课 / 下课 / 上班打卡 | 作息表 + 每节独立铃声，到点弹岛 |
| 番茄钟、专注 25 分钟 | 自定义「一次性倒计时」，结束弹岛收尾 |
| 喝水、久坐、眼保健操 | 自定义定时提醒，文字随便写 |
| 开会、赶车、抢票 | 单点提醒，精确到分钟 |
| 考试、演讲、录屏 | 考试模式：只留小时钟，禁掉所有提示音和弹岛 |
| 桌面时钟 | 迷你岛贴在顶边，静止 6 秒自动变半透明 |
| 看天气 / 看天色 | 底板跟着真实日出日落和云雨雪走 |
| 放首歌 | 到点播放 `Home.mp3`，大岛变成带封面的播放器 |

## 三种「岛」

- **大岛** —— 需要你看一眼的那条消息：上课了 / 下课了 / 自定义提醒 / 麦克风摄像头被占用。宽度随文字自适应，约 5 秒自动收回
- **小岛** —— 倒计时专用：课间显示「距上课 mm:ss」，一次性倒计时显示剩余时间
- **迷你岛** —— 贴屏幕顶边的刘海式时钟，只显示时间；静止 6 秒降到半透明，不挡视线

三个形态之间是**连续变形**的：点迷你岛会平滑长大成大岛，不是先消失再弹出。

## 两个版本，按需选

仓库里有两条并行的线，**可以装在同一台机器上**（安装目录、注册表键、单实例标识、开机自启动项全部独立，互不覆盖）。

| | **Turbo（推荐）** | 主线 v1.2 |
| --- | --- | --- |
| 发布产物 | `mobile-v1.2-Turbo.exe` | `mobile-v1.2.exe` |
| 当前版本 | 1.2.1 | 1.2 |
| 体积 | 约 454 KB | 约 2.1 MB |
| 第三方依赖 | **无** | litehtml + gumbo |
| 源码 | `turbo.cpp`（8166 行） | `mobile.cpp`（8726 行） |
| 岛 | 大 / 小 / 迷你 | 大 / 小 / 迷你 |
| 底板 | 天气模式 / 纯色模式 | 浅色 / 深色主题 |
| 考试模式 | ✅ | ❌ |
| 天空跟随真实日出日落 | ✅ | ❌ |
| AI 对话岛（要自己填 API Key） | ❌ | ✅ |
| 消息岛（最多 6 条气泡并排） | ❌ | ✅ |
| 每节独立铃声 / 播放器 / 天气 / 隐私提示 | ✅ | ✅ |

**怎么选**：想要一个干净、启动快、拷过去就能用的提醒工具 → **Turbo**；想折腾 AI 对话岛、多消息堆叠 → 主线 v1.2。

Turbo 是 v1.2 的**减法支线**：删掉没做完的 AI 岛与多岛并行，修掉触控点击和夜间天色，顺手把每帧白算的活儿砍了，所以体积只有主线的五分之一。

## 功能明细

### 提醒与铃声

- **作息表驱动**：内置三套（见文末），设置里一键切换，选择自动保存
- **每节独立**：11 个节次，每一节的「到点弹岛 / 上课铃 / 下课铃」都能单独勾选，音量各自拖
- **自定义提醒**：大岛上的文字可以改；能加一次性倒计时、能加定时单点提醒；时间段可增删改
- **铃声存法**：开关用位掩码、22 个音量打包成一条二进制值塞进注册表，不占一堆键

### 天空与天气

- **天气模式**：底板颜色跟着当天真实的日出日落走，叠加云、雨、雪；天气数据走 WinHTTP 后台线程，超时短、失败静默，不联网也能用
  - 数据来自公开的 [Open-Meteo](https://open-meteo.com/)，坐标写死在内置参数里（山东淄博一带），**不读定位、不带任何个人标识**
- **纯色模式**：回到一块安静的深灰底，不画天空
- 天空亮度、天空动画（每次重播 / 接着变）、动画速度都能调
- 中秋、国庆（含前一天）自动换节日配色，可关

### 播放器

- 每天 19:30 播放同目录的 `Home.mp3`，大岛变成音乐播放器：左封面 / 中歌名 / 右播放-暂停，支持暂停 5 秒后自动收起
- 封面读同目录的 `Home.jpg`，没有就不显示封面
- 想换歌就换同目录的文件，程序不会覆盖你放过的那份

### 隐私提示

- 麦克风 / 摄像头被占用时弹大岛，左边自绘图标、右边文字
- 数据只读 Windows 自己的「隐私设备使用记录」，不注入、不抓画面、不上传

### 考试模式（Turbo 1.2.1 起）

- 只留迷你岛时间，**其他所有岛一律不弹**；关掉实时天气、底板固定纯色
- **连铃声一起禁**：提示音、《回家》、试听、播放器全部静音；开启那一刻正在放的也会立刻掐掉
- 开启后设置窗口自动关闭；想退出得从托盘重进设置、输二级密码（默认 `426426`，可在「自定义」页改）
- 状态写注册表，重启也躲不掉

### 设置窗口

- 左侧导航 6 页：作息表 / 时间提醒 / 自定义 / 主题 / 迷你岛 / 更多
- 底部常驻运行状态：运行中、现在时间、下次提醒
- 改完即时生效并自动保存；切页保留滚动位置，控件不会闪
- 「立即测试」把全部形态演示一遍（约 28 秒，期间屏蔽真实闹钟）

### 触控

- 点击、长按、从顶边下滑全部按指针消息处理，**手指和鼠标同一套逻辑**
- 挪动超过 12px 算拖动不触发点击；250ms 内只认一次，防止部分设备同时投递两种消息弹两次

## 操作方式

| 动作 | 效果 |
| --- | --- |
| 长按小岛 / 迷你岛 | 关闭 |
| 从屏幕顶边向下滑 | 展开迷你岛 |
| 点迷你岛 / 小岛 | 弹「下节课是…」之类的信息 |
| `Ctrl + Alt + A` | 立刻弹一次大岛 |
| `Ctrl + Alt + S` | 打开设置 |
| `Ctrl + Alt + P` | 演示播放器岛 |
| 托盘图标右键 | 设置… / 退出 |
| 考试模式开着时 | 托盘 → 设置… → 输密码（默认 `426426`）才能进设置 |

## 快速开始

到 [Releases](../../releases) 下载 `mobile.zip`，解压得到：

- `mobile-v1.2-Turbo.exe`：主程序
- `alin.mp3`：上课 / 下课提醒音
- `Home.mp3`：放学《回家》
- `Home.jpg`：播放器封面
- `check.exe`：自检工具，控制台跑一次，同目录生成 TXT 报告

全部放在**同一个目录**，双击 exe：自动安装到 `%LOCALAPPDATA%\IslandAlarmTurbo` 并常驻托盘。

- 首次运行等于全新安装，作息表勾选、音量这些要重新配
- 以后升级只覆盖安装目录里的同名 exe，设置保留
- 确认新版没问题后，把旧版从托盘退出，再走它自己的卸载

> **杀软 / SmartScreen 提示？** 没有代码签名的小众开源工具都会这样。程序不联网做坏事、不写系统目录、不申请管理员权限，源码就在这个仓库里，介意的话自己编。

## 从源码编译

需要 Windows 10 及以上 + MinGW-w64（GCC，支持 C++17），例如 MSYS2。

### Turbo（无第三方依赖）

```bat
windres app.rc -O coff -o app_res.o
g++ -O2 -std=c++17 -mwindows -static -s -o mobile-v1.2-Turbo.exe turbo.cpp app_res.o ^
    -luser32 -lgdi32 -lmsimg32 -lgdiplus -lwinhttp -ladvapi32 -lversion ^
    -lshell32 -lwinmm -lole32 -luuid -lcomctl32
```

### 主线（还要 litehtml + gumbo）

两个库需自行编译，然后按下面的结构放（或改 `LITEHTML_DIR` / `GUMBO_DIR`）：

```
third_party\
├── litehtml\
│   ├── include\litehtml.h
│   └── liblitehtml.a
└── gumbo\
    ├── src\gumbo.h
    └── libgumbo.a
```

```bat
windres app-main.rc -O coff -o app_res.o
g++ -O2 -std=c++17 -mwindows -static -s -o mobile-v1.2.exe mobile.cpp app_res.o ^
    -I"third_party\litehtml\include" -I"third_party\gumbo\src" ^
    -L"third_party\litehtml" -L"third_party\gumbo" ^
    -luser32 -lgdi32 -lmsimg32 -lgdiplus -lwinhttp -limm32 -ladvapi32 -lcrypt32 -lversion ^
    -lshell32 -lwinmm -lole32 -luuid -lcomctl32 ^
    -llitehtml -lgumbo
```

`build.bat` 默认编 Turbo；`build.bat mobile` 编主线；`build.bat check` 编自检工具。

### 链接库都是干嘛的

| 库 | 用途 |
| --- | --- |
| `-lgdiplus` | 解码 `Home.jpg` 封面 |
| `-lwinhttp` | 实时天气 |
| `-lversion` | 读 exe 自己的版本号（自安装时比较新旧） |
| `-lole32` | WASAPI 回环（抓系统输出算音量） |
| `-limm32` | 主线专用：AI 岛输入框的输入法候选窗定位 |
| `-lcrypt32` | 主线专用：DPAPI 加密 API Key |
| `-llitehtml -lgumbo` | 主线专用：AI 岛气泡排版 |

资源脚本有**两份**，别混用：`app.rc` 给 Turbo（版本 1.2.1 / 产品名 Mobile-Island Turbo），`app-main.rc` 给主线（版本 1.2 / 产品名 Mobile-Island）。里面放图标、清单和 VERSIONINFO。**版本号必须跟着发版改** —— 自安装靠它判断「手里这份是不是更新」，没有它新版永远覆盖不了已装好的旧版。清单里声明了 `asInvoker` 和 comctl32 6，别删。

## 自检工具

`check.exe` 是个独立控制台程序，源码在 `check.cpp`，只查「能确定」的东西：系统版本、屏幕尺寸、安装目录与 exe 版本、三个音频文件在不在、注册表值合不合法、自启动项、主程序有没有在跑。运行后同目录生成一份 TXT 报告，失败项会写「可能原因 + 建议」。

```bat
check.exe          直接跑
check.exe --keep   跑完不自动关窗口
```

Turbo 版的注册表键和安装目录都带 `Turbo` 后缀，别拿查主线键的旧工具来查。

自己编：`g++ -O2 -std=c++17 -municode -static -s -o check.exe check.cpp -ladvapi32 -lversion -lshell32`（或直接 `build.bat check`）。

运行时行为（动画、点击判定）它看不到，那些归主程序里的「立即测试」。

## 卸载

```bat
mobile-v1.2-Turbo.exe --uninstall
```

会删开机自启动项和程序目录 `%LOCALAPPDATA%\IslandAlarmTurbo`；设置仍留在 `HKCU\Software\IslandAlarmTurbo`，要彻底清就手动删这个键。卸载不影响同机安装的主线 v1.2。

## 常见问题

**为什么叫 Island？**
因为提醒弹出来就是屏幕顶上的一块岛 —— 手机上的「灵动岛」长什么样，它就是那个意思。搜 `Mobile-Island` 找的就是这个。

**能不用学校作息吗？**
能。设置 → 自定义里加了单点提醒和一次性倒计时，跟作息表无关；作息表只是「一整天按节次自动跑」的那条路。

**支持多显示器吗？**
岛的位置按**主显示器**计算，副屏不弹。想让它出现在别的屏幕上，得把那个屏设成主屏。

**会不会上传我的数据？**
不会。联网只有一件事：向 Open-Meteo 请求当天天气和日出日落，不带任何个人标识；麦克风摄像头提示读的是本机记录；没有遥测、没有自动更新服务器、没有账号。

**能改成立即静音 / 一键停止吗？**
考试模式就是干这个的（Turbo 1.2.1 起）；平时把托盘 → 退出即可。
