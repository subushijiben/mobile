# mobile · 教室上下课提醒

一个 Windows 桌面小工具：到上下课时间，屏幕顶部会弹出一个类似手机「灵动岛」的提醒并响铃。单文件、免安装，双击即可自动部署并常驻托盘。

使用纯 Win32 API + 分层窗口（Layered Window）全自绘，无任何第三方 UI 框架依赖。

## 功能特性

- **三档「岛」**
  - 大岛：上课 / 下课 / 自定义提醒时弹出，显示事件与时间，约 5 秒后自动收回
  - 小岛：课间出现，显示「距上课 mm:ss」倒计时
  - 迷你岛：贴在屏幕顶边的刘海式小时钟，只显示实时时间；静止 10 秒后自动降到约半透明，不遮挡桌面
- **提醒音**：上课铃、下课铃可分别调节音量并试听；只有勾选的时段才响铃，未勾选时段只显示倒计时
- **特殊节日皮肤**：中秋、国庆（含节前一天）自动切换节日配色；可在设置中关闭
- **设置窗口**：时段勾选、提醒音、主题、迷你岛、开机自启动，改动即时生效并自动保存
- **操作方式**
  - 长按小岛 / 迷你岛：关闭
  - 从屏幕顶边向下滑：展开迷你岛（支持触控屏）
  - `Ctrl + Alt + A`：立刻弹一次大岛（测试用）
  - `Ctrl + Alt + S`：打开设置窗口
- 设置保存在注册表 `HKCU\Software\IslandAlarm`

## 快速开始

到 [Releases](../../releases) 页面下载最新的 `mobile-v1.0.exe`，双击运行即可：程序会自动完成部署并常驻托盘。

> 铃声文件 `alin.mp3` 需要放在 exe 同目录下（程序运行时会自动查找）。仓库不附带该音频文件，请自行准备。

## 从源码编译

### 环境要求

- Windows 10 及以上
- [MinGW-w64](https://www.mingw-w64.org/) 工具链（GCC，支持 C++17），例如 MSYS2、Dev-C++ 自带的 g++

### 编译命令

```bat
g++ -O2 -std=c++17 -mwindows -static -s -o mobile.exe mobile.cpp ^
    -luser32 -lgdi32 -lmsimg32 -ladvapi32 -lshell32 -lwinmm -lole32 -luuid -lcomctl32
```

也可以直接运行仓库中的 `build.bat`。

> 原项目编译命令中的 `app_res.o` 仅含可选的版本信息资源，程序本身不依赖自定义资源（托盘图标使用系统默认图标），不链接它不影响功能。

## 卸载

在命令行中运行：

```bat
mobile-v1.0.exe --uninstall
```

会删除桌面快捷方式与开机自启动项；设置仍保留在注册表 `HKCU\Software\IslandAlarm` 中，如需彻底清除可手动删除该键。
